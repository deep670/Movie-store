# 🎬 Movie Store

A full-stack **Movie Store web application** where users can browse movies, add them to their cart, purchase movies, and make payments through **Razorpay**.

This project was built with the help of AI, allowing me to focus more on implementing real-world features, user experience, authentication, payment integration, and backend functionality.

## 🚀 Key Features

* 🎥 Browse and explore movies
* 🔍 View movie details
* 🛒 Add movies to cart
* 💳 Purchase movies through Razorpay
* 📚 Access purchased movies from your library
* 🔐 Secure JWT-based authentication
* 👤 User registration and login
* 🛡️ Admin dashboard
* 🎬 Admin can manage movies
* 🗄️ MongoDB database
* ⚙️ Custom Node.js & Express REST API
* ☁️ Deployed on Vercel

## 💳 Payment

The application uses **Razorpay Payment Gateway**.

> ⚠️ Razorpay is currently running in **Test Mode**.

You can use the available test payment options to experience the complete movie-purchase flow without making a real payment.

## 🛍️ How It Works

1. Create an account or log in.
2. Browse the available movies.
3. Select a movie you want to purchase.
4. Add it to your cart.
5. Proceed to checkout.
6. Complete the Razorpay test payment.
7. After successful payment, the movie becomes available in your **Library**.

* **Frontend:** HTML, CSS, JavaScript

* **Database:** MongoDB
